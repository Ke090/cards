# POCKET GACHA

小さな出会いを、ポケットに。無料でガチャをひき、15種類のキャラ・アイテムを集めるWebアプリです。課金・ログイン・バックエンドはありません。

## Windowsで起動
1. Node.js **22系の22.13以降、24系、または26以降**（npmを含む）をインストールします。検証環境は22.17.0です。
2. **`start-local.bat`** をダブルクリックします。
3. 依存関係のインストール後、**http://127.0.0.1:5173** が開きます。
4. 終了時は起動ウィンドウで `Ctrl+C` を押します。

batは毎回 `npm ci` でlockファイルに合わせます。初回・キャッシュがない場合はネット接続が必要です。5173番ポートが使用中の場合は既存サーバーを終了してください。batのメッセージは文字化けを避けるため英語です。

## コマンド
```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```
devは127.0.0.1:5173固定です。previewは通常127.0.0.1:4173で起動し、先にbuildが必要です。

## 仕様と保存
- 通常14種類（各96÷14%、約6.857%）と、レア「ほしの王さま」（4%）。毎回独立抽選し、レア確定保証はありません。画面は小数第3位に丸めて表示します。
- 新たにうさぎ・きつね・ペンギン・きのこ・くじら・おばけ・真珠・ポット・ランタン・かぎの10種類を追加。既存5種類の所持データは引き継ぎます。
- ガチャをひくと、回転→上から落下してバウンド→タップ→光が漏れる→上下の殻が開く→アイテム登場→獲得結果の演出が流れます。レアは光の予兆、金色のカプセル、放射光、多めの紙吹雪と専用効果音・ファンファーレです。
- 「演出の動き」で自動（OSに合わせる）／しっかり再生／ひかえめを選べます。設定は保存されます。動きが見えないときは「しっかり再生」を選んでください。「演出おためし」の通常・レアで確実に各演出を確認でき、所持数や抽選回数は増えません。
- 「演出をスキップ」またはEscapeで結果へ進めます。スキップ・連打で抽選回数は増えません。
- 効果音はWeb Audioによるオリジナル合成音。最初の操作後に鳴り、ヘッダー・演出・結果画面の「音 ON/OFF」で切り替えられます。設定はブラウザーに保存され、OFFにすると再生中の音も止まります。
- 音声非対応・再生拒否の環境でも音なしで遊べます。ページを隠したときは再生中の音を停止します。OSの動きを減らす設定では待ち時間・動きを省略し、カプセルを開く操作は残します。
- 重複時は所持数が増えます。抽選結果は演出開始時に保存されます。
- 獲得済みの絞り込みと、提供割合の確認ができます。
- 保存先はlocalStorageです。別の端末・ブラウザー・ホスト・ポートは別の保存領域です。ブラウザーのサイトデータ削除でリセットされます。
- 保存禁止・容量不足・不正データの場合は通知し、メモリー上で続行します。
- 同時に複数タブでのプレイは想定していません。1つのタブで遊んでください。

## 構成
TypeScript（strict）＋Vite＋ネイティブDOM/CSS。production dependencyなし。npm / package-lock.jsonを使用します。

| パス | 役割 |
| --- | --- |
| `src/main.ts` | UI、演出、ダイアログ、ブラウザー保存 |
| `src/catalog.ts` | アイテム定義と確率の重み |
| `src/game.ts` | 抽選・所持数・保存データ検証 |
| `src/draw-sequence.ts` | 演出段階・タイマー・スキップ制御 |
| `src/motion.ts` | OS設定とアプリ内の動き設定の解決 |
| `src/capsule-animation.css` | 落下・バウンド・分離開封・レア専用演出 |
| `src/sound.ts` | Web Audio効果音・ミュート・音声非対応処理 |
| `src/style.css` | レスポンシブUI、アニメーション |
| `src/effects.css` | カプセル開封、光、紙吹雪、サウンドボタン |
| `public/assets/collection.png` | AI生成のアイテム画像アトラス |
| `public/assets/*.png` | 追加10種類の生成画像（個別ファイル） |
| `tests/game.test.ts` | 確率境界・重複・保存データの検証 |
| `tests/draw-sequence.test.ts` / `tests/sound.test.ts` | スキップ・連打・短縮演出・音声停止・音声非対応 |
| `scripts/start-local.mjs` / `start-local.bat` | Windows起動補助 |
| `.github/workflows/ci.yml` | lint / typecheck / test / build |

環境変数・API・DB・migration・認証はありません。APIキーも不要です。初期リポジトリには短いREADMEしかなく、既存実装・規約・CIはありませんでした。

## アイテム追加
`src/catalog.ts`に不変で一意のID、名称、説明、rarity、正のweight、artなどを追加します。確率・表示件数・達成率は配列から計算します。新しいIDがない旧保存も読めます。追加の個別画像は `art: { url: '/assets/new.png', position: 'center', size: 'contain' }` と指定すれば、既存の画像アトラスやCSSを変更せず追加できます。15種類・レア1種類・レア4%の仕様テストは仕様変更に合わせて更新してください。

## ローカル確認
- batで起動し、演出中の連打で余分な抽選が起きないこと。
- 「もう一度ひく」「コレクションを見る」、絞り込み、提供割合が動くこと。
- 重複で所持数が増え、再読み込みしても記録が残ること。
- レア演出（4%なので出ない場合あり）、スマートフォン幅、キーボード操作。
- OSの「アニメーションを減らす」設定で演出が短くなること。
- カプセルのタップ開封、スキップ、回転音・開封音・通常/レアの獲得音を確認すること。
- 音OFFがすぐに効き、再読み込み後もOFFが保持されること。
